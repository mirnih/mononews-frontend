# Mononews Frontend

Клиентская часть музыкальной новостной платформы Mononews, разработанная на HTML, CSS и JavaScript. Сайт содержит новости музыкальной индустрии, обзоры исполнителей и альбомов, анонсы концертов и интерактивные страницы.

## Стек технологий

- **HTML5** — семантическая разметка страниц и веб-форм
- **CSS3** — стилизация, Flexbox, Grid, Media Queries
- **JavaScript (ES6+)** — клиентская логика и работа с DOM
- **Fetch API** — асинхронные HTTP-запросы
- **LocalStorage** — хранение пользовательских отзывов
- **Markdown-it** — отображение Markdown в отзывах
- **JSONPlaceholder** — внешний REST API для демонстрации загрузки данных

## Функциональность

- Многостраничный интерфейс с разделами новостей, обзоров, концертов, статистики и обратной связи.
- Адаптивная вёрстка для различных размеров экранов с использованием CSS Grid, Flexbox и Media Queries.
- Интерактивная навигация с подсветкой активной страницы.
- Динамическое создание и обновление элементов страницы средствами JavaScript.
- Форма обратной связи с валидацией полей, добавлением и редактированием отзывов.
- Сохранение отзывов в LocalStorage с восстановлением после перезагрузки страницы.
- Поддержка Markdown-разметки в тексте отзывов через библиотеку Markdown-it.
- Загрузка публикаций из внешнего REST API с использованием Fetch.
- Обработка состояний загрузки, ошибок HTTP-запросов и отсутствия интернет-соединения.
- Динамическое отображение публикаций с помощью HTML-шаблонов.
